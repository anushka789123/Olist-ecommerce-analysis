# Olist-ecommerce-analysis
End-to-end Brazilian e-commerce analysis using Python, SQL, and Power BI, covering sales, customers, products, payments, reviews, and delivery performance.

The project covers the complete analytics workflow — **data cleaning → exploratory analysis → SQL analysis → Power BI dashboard → business insights**.

---

## 📌 Project Overview

The objective of this project was to analyze Olist's Brazilian e-commerce data and understand key business and customer trends.

The analysis focuses on:

- Sales and order performance
- Product category performance
- Customer distribution
- Payment methods
- Customer reviews
- Delivery performance
- Geographic sales distribution
